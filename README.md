# RetentionOS Tools

Internal tools and utilities for RetentionOS — built and maintained by [Bort Ventures, LLC](https://bortventures.com).

## What's here

| Tool | File | Purpose |
|---|---|---|
| Tools Index | `index.html` | Landing page linking everything below |
| State Time Board | `RetentionOS_State_Timezone_Clock.html` | Live clock across every licensed state, grouped by timezone, with calling-hours indicators |
| Call Disposition Tracker | `RetentionOS_Call_Disposition_Tracker.html` | Manual call logging — duration, billable status, disposition — with running closing percentage |
| Save My Contact | `Osvaldo-Bort.vcf` | Client-facing vCard for Rainbow Insurance Agency's save-my-contact workflow |

## Live site

Hosted via GitHub Pages: `https://[username].github.io/retentionos-tools/`

## Notes

- These are self-contained tools — no build step, no external dependencies beyond a font import.
- The Call Disposition Tracker stores data locally in the browser; it does not sync across devices.
- New tools get added to this repo and linked from `index.html` as they're built — see the RetentionOS IP Asset Log for the full history of what's been added and when.
